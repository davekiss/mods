# mods

Claude Code mods by [Dave Kiss](https://github.com/davekiss).

```
/plugin marketplace add davekiss/mods
```

| Mod | What it does | Install |
|---|---|---|
| [leaks](leaks) | Finds where your Claude Code week went and fixes it: `/leaks` ranks the avoidable spend in your transcripts with one-press fixes, and a strip above the prompt flags a leak while it happens. | `/plugin install leaks@davekiss` |
| [shot](https://github.com/davekiss/shot) | Headless macOS screenshots for agents: capture, mark up, redact, record and find screenshots without taking focus. Bundles the shot MCP server, a skill, /shot and a history pane. | `/plugin install shot@davekiss` |
| [env](https://github.com/davekiss/env) | Edit .env files in a pane inside Claude Code. Claude manages keys and asks you for values without ever seeing them. | `/plugin install env@davekiss` |
| [md](https://github.com/davekiss/md) | Read, write and review markdown with Claude in a pane inside Claude Code: drafts stream in, comments stay on their words, and Claude suggests edits you accept or reject. | `/plugin install md@davekiss` |
